# Tikovia CRM

Hệ thống quản lý khách hàng, nội dung truyền thông và tự động hóa xuất bản đa kênh cho doanh nghiệp và Agency.

## 🚀 Công nghệ sử dụng
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide React
- **Backend:** Node.js, Express, Multer, Axios, Googleapis
- **Database:** Supabase (PostgreSQL)
- **Tự động hóa:** n8n Webhook & Meta Graph API

## 📂 Cấu trúc thư mục
- `/frontend`: Giao diện người dùng CRM (Quản lý kế hoạch, bài viết triển khai, kênh...)
- `/backend`: API server xử lý webhook, đồng bộ, upload file và automation
